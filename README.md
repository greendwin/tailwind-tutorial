# Learn Tailwind CSS: a hands-on course

A self-paced Tailwind CSS v4 course. You read short lessons, build UIs by hand, and get reviews from Claude Code. There are no quizzes.

```bash
npm install
npm run dev        # → http://localhost:5173
```

Then open **00 · Start here** on the dashboard.

Talk to Claude Code in this folder:

| Say | You get |
| --- | --- |
| `where was I?` | your progress and what's next |
| `check 05.2` | a review of your exercise, with progress recorded |
| `hint for 06.1` | a nudge, getting more specific each time you ask |
| `explain peer` | an explanation with a snippet for the playground |
| `challenge me` | a new "recreate this design" challenge |

Install the **Tailwind CSS IntelliSense** VS Code extension, and hover over classes to see their CSS.
