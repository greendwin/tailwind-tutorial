# Challenges

Extra "recreate this UI" practice, generated by Claude when you say **`challenge me`**.

Each challenge is a folder:

```
challenges/03-pricing-table/
  BRIEF.md      what to build, difficulty, which lessons it exercises
  target.html   the finished design. LOOK at it in the browser, don't read its source!
  mine.html     your attempt (starts empty)
```

Open both from the dashboard, put them side by side, and recreate the target as closely as you can. Then say `check challenge 03`.
